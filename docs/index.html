GRATIS · 3 MINUTOS

Cómo instalar Hook Machine en Claude

La skill que escribe los títulos de tus reels y anuncios con fórmulas que ya funcionaron. Le das un tema y te devuelve 3 hooks listos para grabar.

  • 💻 Hazlo desde el computador, en claude.ai o en la app de escritorio de Claude.
  • ✅ Funciona con cualquier plan de Claude, incluso el gratis.
1

Descarga la skill

⬇ Descargar la skill

Se baja un archivo llamado hook-machine.zip. No lo descomprimas: Claude lo necesita así.

2

Activa la ejecución de código

Se hace una sola vez. Entra a Configuración y busca:

Configuración → Capacidades → Ejecución de código en la nube y creación de archivos

Déjalo encendido. Claude dice ahí mismo que es necesario para las habilidades.

3

Súbela a Claude

Entra a Personalización → Skills. Toca + Añadir y después Subir habilidad.

Arrastra el archivo hook-machine.zip al recuadro (o haz clic ahí para buscarlo) y toca Subir. Claude le pasa un análisis de seguridad y la deja instalada.

4

Pídele tus hooks

Abre un chat nuevo y escribe:

tu chat con Claude
❯ hooks para mi próximo video: [tu tema]

Te devuelve algo así:

hook-machine
3 opciones, con formato ganador:

01 · Promesa numerada → 3 agentes que venden mientras duermes
02 · Kicker → Nadie te lo dijo: tu CRM ya puede contestar solo
03 · A vs B → Vender antes de Claude / después de Claude

Cada opción trae también lo que dices a cámara en los primeros segundos, y al final te dice cuál probaría primero y por qué.

💡 Para que escriba con tu voz: pégale el texto de 3 a 5 de tus publicaciones (captions o guiones) y después pídele los hooks.

¿Usas Claude Code?

Pega esto en Claude Code y él la instala solo:

Claude Code
Instala esta skill de Claude Code: clónala desde https://github.com/diegodoc1111/hook-machine dentro de ~/.claude/skills/

Si algo no funciona

No me aparece “Subir habilidad”

Revisa el paso 2: la ejecución de código tiene que estar encendida. Y hazlo desde el computador.

Claude dice que el archivo no sirve

Sube el .zip tal cual lo descargaste. Si lo descomprimiste y lo volviste a comprimir, bájalo otra vez desde el botón del paso 1.

Abre un chat nuevo después de instalarla y usa la palabra “hooks” o “ganchos” en lo que le pides.
